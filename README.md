# Job Hunter Bot

Телеграм-бот который каждый день ищет стажировки и junior вакансии по аналитике данных на hh.ru, оценивает их через LLM и присылает дайджест.

## Как это работает

1. Selenium парсит вакансии с hh.ru по заданным поисковым запросам
2. DeepSeek API оценивает каждую вакансию по профилю соискателя от 1 до 10
3. Подходящие вакансии отправляются в Telegram с кнопками
4. Можно отмечать отклики и менять их статус прямо в боте

## Стек

- Python
- Selenium + BeautifulSoup
- DeepSeek API
- python-telegram-bot

## Установка

1. Клонируй репозиторий
2. Установи зависимости: pip install -r requirements.txt
3. Создай файл `.env` по образцу `.env.example` и заполни свои ключи
4. Запускай: python main.py

## Настройка

Все параметры поиска задаются в `config.py`:
- `SEARCH_QUERIES` — поисковые запросы
- `MIN_SCORE` — минимальная оценка для попадания в дайджест (по умолчанию 6)
- `SEND_TIME` — время автодайджеста (по умолчанию 09:00)
